# battlezone-arena-2025
Built this neon-themed esports landing page during the Cerebro Challenge 2025 at IITM.
Made in ~70 minutes using HTML, CSS, JavaScript, GSAP, Three.js, and tsParticles.

Result: 1st Runner-Up (2nd Place)

Features
	•	Neon UI design
	•	GSAP animations
	•	Three.js 3D grid
	•	Particle effects
	•	Trailer modal
	•	Light/Dark mode

How to run

Just open index.html in any browser.
